# 手掌擋板

一個安卓 App。它在所有 App 的畫面下方放一塊半透明擋板。手掌放在擋板上，不會點到下面的 App。

適合一般電容筆。平板分不出電容筆和手指，所以這個 App 不猜哪個是手掌，而是直接擋住一塊區域。

## 安裝

1. 在平板用 Chrome 打開 `palm-guard.apk` 的下載連結。
2. 下載完按「開啟」，照畫面允許安裝。
3. 打開「手掌擋板」，照 App 裡的第 1 步、第 2 步做。

## 限制

- 擋板那塊區域完全不能點。要點下面的東西，先把擋板隱藏或拖低。
- 擋不到的地方（擋板上面）手掌碰到還是會誤觸。寫字時把筆記往上捲，讓正在寫的那一行在擋板上面。
- 系統手勢（例如從最下面往上滑回主畫面）擋不住。

## 自己重新打包

需要 Java 17 以上。把 `build.sh` 開頭列的四個工具放在同一個資料夾，然後執行：

```
TOOLS=/放工具的資料夾 ./build.sh
```

`debug.keystore` 是簽名用的鑰匙，密碼是 `android`。用同一把鑰匙簽，新版才能直接蓋過舊版安裝。
